## OMS Sensemaking Module
Python module used to perform analytics on OMS data

### Setup
Prerequisites
* Python 3.10.13

### Installation
```
cp .env.template .env
python -m venv venv/
source venv/bin/activate
pip install -U pip setuptools
pip install -r requirements.txt
pip install -r dev-requirements.txt  # Optional for Development
```

### Running Unit Tests
```
pytest
```
