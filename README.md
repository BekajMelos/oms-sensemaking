# OMS Sensemaking

Microservice that provides analytics for OMS data.


## Reference

- [Setting up an OMS Sensemaking Development Environment]

The *OMS Sensemaking* project is documented using [mkdocs] and [mkdocstrings].
Once you have a development environment installed, you can host a local copy of
the project documentation with `mkdocs serve`, which will host the project at
http://localhost:4000 or build a static copy with `mkdocs build` (the resulting
static site will be located in the `site` directory).

The project documentation includes a development guide that covers development
environment configuration, application configuration, and packaging as well as a
dynamically generated API reference and OMS Sensemaking quickstart guide.

[mkdocs]: https://www.mkdocs.org/
